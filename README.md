# Arquitectura de Software - Proyecto ERP

Este repositorio documenta la arquitectura del Sistema ERP, desarrollado
como parte de un taller de ciclo de vida de desarrollo de software,
desde la captura de requisitos ágiles hasta el diseño de una
arquitectura documentada con la plantilla arc42.

## Contenido del repositorio

- **Backlog del proyecto (Notion):** https://half-quill-d23.notion.site/Proyecto-ERP-hannah-Segura-3c77cdcf16b180a38922f85289339e01
- **Documentación de arquitectura (arc42):** ver carpeta [`/documentos`](./documentos)
- **Diagramas (C4, Secuencia, MER):** incluidos dentro de la carpeta `/documentos`

1. Introducción y Objetivos
