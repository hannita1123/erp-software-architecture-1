# Glosario

| Término | Definición |
|---|---|
| **ERP** | Sistema de Planificación de Recursos Empresariales (Enterprise Resource Planning), que integra los distintos procesos de negocio de una empresa en una sola plataforma. |
| **Producto** | Bien o artículo que la empresa compra a proveedores y mantiene en su catálogo, identificado por nombre, descripción y unidad de medida. |
| **Proveedor** | Empresa o persona externa que ofrece productos a la organización, con la cual se gestionan las compras. |
| **Orden de Compra** | Documento formal mediante el cual la empresa solicita a un proveedor la entrega de determinados productos y cantidades. |
| **Stock** | Cantidad disponible de un producto en el inventario de la empresa. |
| **SPA (Single-Page Application)** | Aplicación web que carga una sola página HTML y actualiza su contenido dinámicamente sin recargar el navegador. |
| **API (Application Programming Interface)** | Conjunto de reglas y endpoints que permiten la comunicación entre la SPA y el backend del sistema. |
| **MER** | Diagrama de Entidad-Relación, que modela cómo se relacionan los datos dentro de la base de datos. |
| **C4 Model** | Metodología de diagramación de arquitectura de software organizada en niveles: Contexto, Contenedores, Componentes y Código. |
